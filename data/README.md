# Data

The data file is not included in this repository.

The analysis uses `NGDB_merged_clean.csv`, a cleaned and merged copy of USGS National Geochemical Database (NGDB) records distributed on Kaggle
(dataset *USGS National Geochemical Database (NGDB)* by Behrouz Darvishzad; check the Kaggle page for its license and version).

Original source: U.S. Geological Survey, *Geochemical data for rock, sediment, soil, and mineral samples, United States and territories, 1962 to 2023* (Granitto et al.), data release, https://doi.org/10.5066/P1FXE9GK.
The Kaggle copy may predate the latest USGS release.

Place the file here as `data/NGDB_merged_clean.csv` before running the notebook.
